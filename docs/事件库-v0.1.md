- 施颠：创新欲 95 → 发明流/版本研究类权重 ×2.5；心态 90 → 被甩锅后触发「施颠笑着接锅」概率 70%，红温类 ×0.3；甩锅倾向 10 → 作为甩锅者的事件 ×0.2；作为背锅者的事件 ×3。

- 地鼠：话痨高 → 休息时「如何评价」类 ×3（文案自动插入口头禅「如何评价」）；对局中话痨效果 ×0.2（打游戏认真）；17:00 后在场概率 ×0.35。
- 弟必：发育 65 → 逆风 30 分钟后翻盘类 ×2.5；对线 35 → 前期被单杀类 ×1.8；话痨低 → 争吵类作为发起者 ×0.3。
- 吊龙：团队 70 → 复盘/指挥/阵容讨论 ×2；局势紧张（比分差≥5 或比赛中）话痨效果 ×0.2，轻松时段子类 ×2；也会甩锅施颠（×1.5）。
- 批菊：嘴硬 85、对线 33 → 「被单杀」后接「嘴硬不认」70%、「转移火力到施颠」50%；每次被单杀累加觉醒进度。
- 通用：甩锅倾向≥60 输局后甩锅 ×2；话痨≥60 休息时开话题 ×2；摸鱼倾向≥50 时摸鱼行为基础概率 +50%；胜负心≥70 加班概率 ×1.5。

### 2. 状态修饰

- 体力<30：摸鱼/睡着类 ×2.5，练习收益 ×0.6；体力<15 可触发生病。
- 心情<35：红温、阴阳怪气、赌气类 ×2；心情>75：段子、请客、背后夸人 ×1.5。
- 专注<30：排队时摸鱼 ×2（沿用草案示例）；专注>70：补刀练习、复盘开窍 ×1.5。
- 手感>80：超神/五杀概率 ×3；手感<30：送人头、空大 ×2.5。
- 饥饿>70：外卖/零食/拼单 ×3，所有对局手感 -10。

### 3. 时段修饰

- 早到（7:30–8:59）：仅早到者在场，单人练习收益 ×1.2；施颠、吊龙早到概率高；可触发「早到第一人」「施颠早到练怪」「吊龙早起买早餐」。
- 上午（9:00–11:30）：单排为主（组排概率 30%）；周一上午专注 -10；迟到判定窗口 9:05–10:00。
- 午饭（11:30–13:00）：生活类 ×3，对局类 ×0.3；外卖、选择困难、地鼠点评。
- 下午困（13:00–15:00）：闭目养神/睡着 ×2.5，被拍照 ×2；15:00–16:30 奶茶、桌游、下午茶话会 ×2。
- 下午组排（13:30–17:00）：人齐时组排概率 60%。
- 赛前（距周赛≤2天 / 杯赛周）：组排比例 → 80%，摸鱼 ×0.6，监督 ×1.5，比赛准备类解锁，事件密度 +30%。
- 加班（17:00–23:00）：地鼠在场 ×0.35；在场人数≤2 时触发夜宵/关灯；次日体力-15并加权「熬夜后摸鱼」。
- 周五下午：心情+5，「赦免日」解锁；周一：「周一综合征」。

### 4. 多人组合事件

- 2人：槽位从在场者中按关系值抽取。关系≥70 优先抽包庇/双排/陪练/护短；关系≤30 优先抽冷战/阴阳/空调大战；把柄存在时优先抽把柄交易。
- 固定双人组合：当邓+批菊 → 「批菊当邓联合点评」（对象施颠）；地鼠+任意争吵双方 → 「地鼠和事佬」；吊龙+批菊 → 复盘教学。

- 槽位约束：同一事件内一人只占一个槽；专属事件槽位锁定本人；天意事件不可与「管理员」字样同屏，文案和自然事件共享模板池。

### 5. 冷却与去重

- 每条事件有 cooldownMinutes（按参与者计）；0 表示由流程或阈值控制、一次性（如性格转变）。
- 同类别对同一人 30 分钟内最多 2 条有趣级；同一人每日剧情级最多 2 条；全办公室剧情级每日 1–3 条、重大级每周 0–2 条（比赛除外）。
- 文案变体轮换：同事件 7 天内不重复使用同一变体；无可用变体时降级为日常灰字。
- 连锁加权当日 24:00 清零；同一链条同一参与者 3 天内不重复开启（比赛链除外）。
- 去重：同一分钟同一参与者只输出一条事件；同义事件（停电/突然停电）共享 1440 分钟互斥窗口。
- 一次性里程碑（当邓不投了、批菊抗压觉醒、地鼠冲铂金、发明流绝活成型、弟必对线开窍、吊龙指挥升级）触发后永久关闭，改为在个人主页记录。
