# SSB电竞经理 v0.4.0-pre

网页试玩版。构建产物是单个 `index.html`，双击就能玩，不需要安装，也不是 Electron。

`game/package.json` 的版本号是 `0.4.0`。开始菜单副标题和浏览器标签写的是 **网页试玩版 · v0.4.0-pre（M4）**。

## 怎么打开

```bash
cd game
npm install
npm test
npm run build
```

然后双击 `game/dist/index.html`。开发时用 `npm run dev`。

这次预发布构建出的 `game/dist/index.html` 是 **840,626 字节**（Vite 报 840.63 kB，gzip 251.24 kB）。脚本和样式都打进这一个文件，没有外链 JS。旁边的 `favicon.ico`（4,286 字节）只是标签页图标，没有它也能玩。`dist/` 不进仓库。

操作：空格暂停 / 继续，`1` / `2` / `3` 切换正常 / ×3 / ×10，`Esc` 打开存档菜单。拖动旋转，滚轮缩放，点人物看卡片。顶部「经营」做老板动作、买设施、签赞助。

存档在浏览器里（1 个自动存档 + 3 个手动槽位）。换浏览器或清缓存会丢，重要进度用「导出存档」。当前存档版本是 **v6**（休赛期、世界赛、谈薪、训练路线）。更旧的存档打开时会自动迁移。

## 这一版能玩什么

M1 到 M4 都在这一版里。M5 只接了第一刀。

**M1 · 时间与日常**

- 09:00–22:00 的可见白天，正常档大约等于现实 10 分钟；可暂停，可 ×3、×10。22:00 后夜间快进，屏幕提示大家都下班了。
- 六段作息，六人按性格自己活动。事件看板默认展开日常。第 1 天 09:00 固定有「战队成立」。
- 开局场地是星空网吧角落。

**M2 · 外卖与经营**

- 饭点外卖，16 道菜。默认自己付钱；「今天我请」或公司餐补走公司账。
- 老板动作和每日行动点。现金、训练心得、月薪房租、私房钱、赞助、可购设施。开局公司现金 5,000，私房钱 20,000。连续 3 个月发不出工资才破产。

**M3 · 比赛**

- 比赛日 18:30 确认五人首发和战术，19:00 看直播（节点、击杀、解说、弹幕），不能一键出结果。
- 网吧联赛 BO1；城市联赛起 BO3，局间可以换人、换战术。
- 网吧、城市、国内各 8 队双循环。前 2 升级，后 2 降级。网吧联赛垫底不降级。

**M4 · 场地、世界赛、结局**

- 休赛期可以搬家、改训练路线、谈赞助、谈薪。
- 国内前 2 在休赛周打世界赛：八强、半决赛、决赛，BO3，每两天一场。
- 世界赛夺冠会弹出主结局。点「继续经营」可以接着打。

**已经接上的 M5 第一刀**

- 开局六人：阿鸡、当邓、狗粮、弟必、吊隆、撇干。
- 看板上有名场面、互怼、甩锅、摸鱼、交情和心结的切片。

## 调试

只有地址带 `?debug=1` 时，左上角才会出现「调试」面板，默认收起。不加这个参数，页面上没有调试入口。

只加 `?debug=1` 仍停在标题。要直接进入可玩的一局，再加上 `&skip=1`，或沿用 `&t=`、`&venue=`。

常用跳转：`?day=2&t=18:20&skip=1` 到第 2 天赛前。面板可以改时间、现金、行动点、场地，也可以跳到下一场比赛、下一次发薪、赛季末，或直接触发世界赛和夺冠。这些改动不写进存档格式。

## 已知未做

- **人物造型挂起。** 画面仍是现在的低多边形几何体（稿 B 剪影）。本预发布不改造型。
- **训练路线每日成长还没接上。** 休赛期可以改路线，磨合期会掉一点心情；不会按路线每天涨属性。
- **基地没有新户型。** 电竞基地、豪华基地仍是小办公室那张平面，只换墙色和招牌。豪华基地的新设施还没上架。
- **默契连招专名待定。** 狗粮×吊隆（下路）、弟必×当邓（中野）在游戏里不另起专名，占位就是「【待定】」。
- **M5 事件库未扩完。** 227 条事件和连锁仍在素材库（`docs/事件库-v0.1.md`、`data/events.json`），没有整库接入。数值平衡、其余连招名也还没定。
- **不是 Electron。** 没有 Windows .exe。M6 再做打包。游戏代码不调用 Node 或 Electron。
