## 1. 核心定位【已定】
- **第一亮点：队员都是现实中的朋友。** 人物之间的互动、事件看板（群聊 + 体育解说文风）是游戏核心。
- **第二：电竞经理玩法**，组队、训练、打联赛、升级场地。
- **情绪基调：温暖的兄弟团，不搞宫斗。** 矛盾只是笑料和小波折，最后都会化开。
- **节奏分工【已定】**：比赛日是玩家最忙、交互最多的时候；非比赛日（训练日）像 QQ 宠物式养成，队员按各自性格自主活动，玩家以观察为主，偶尔出手，整体要有很强的生活感。
- 设计原则：任何系统设计都先问“能不能产生有趣的人物互动”，其次才看数值。

## 2. 平台与表现【已定】
- 平台：正式发行 Windows 优先，macOS 后续。
- 技术栈：沿用 Claude 样板的 Vite + Three.js + TypeScript；以后可接 Steam，同一套代码可出 macOS 版。
- **分两个阶段【已定】**：
  1. **前期：HTML 网页版**。开发主要在 macOS 上进行，构建产物是可双击打开的单文件 HTML（沿用样板的 vite-plugin-singlefile），也可以用 `npm run dev` 在浏览器里跑。用来在 Mac 上试玩、发给朋友。
  2. **后期：Electron 打包**。把同一份构建产物套进 Electron 外壳，出 Windows .exe（后续 macOS 包）。.exe 放在 Windows 机器或 CI 上构建。
- **为后期打包守住的约束**：
  1. 存档、设置、窗口等平台相关功能统一走一个 `platform` 接口层：网页版用浏览器存储（IndexedDB / localStorage）实现，Electron 版换成本地文件实现，游戏逻辑不改。
  2. 网页版的存储跟着浏览器走（清缓存会丢，`file://` 下不同浏览器的行为也不同），所以必须提供**导出 / 导入存档**（JSON 文件），以后也用它把存档迁移到 exe 版。
  3. 游戏代码不直接调用 Node / Electron API，不读写任意路径，保证网页版一直可用。
  4. 字体、模型、贴图全部打进包里，不依赖网络和系统字体，离线可玩。
- 视觉：沿用 Claude 样板的 3D 等距办公室风格。模型精修**暂缓**。
- 玩家上帝视角，不出镜；点击人物可看状态、关系和近期事件。
- 技术细节参考 `claude-v1/迷你世界-决策文件包/技术架构方案.md`，其中“服务端常驻 / WebSocket 广播 / 公开访问”部分作废。以下可沿用：确定性随机（种子）、事件条件 DSL、权重公式、槽位分配、冷却与连锁、模板文案。

## 5. 属性与成长
### 5.1 属性【沿用，需合并】
- 旧草案分三层：能力（操作、意识、对线、发育、团队、英雄池）、性格（嘴硬、心态、胜负心、逆风意志、创新欲、话痨、摸鱼倾向、甩锅倾向）、状态（体力、心情、专注、手感、饥饿）。
- 灵感版比赛引擎有 7 属性（lane/roam/fight/sense/mech/pool/mental），另有位置适性 fit、潜力 potential、特性 traits，以及疲劳、压力。
- **合并方案【已定】**：
  - 能力层直接用引擎的 7 属性：对线 lane、游走 roam、团战 fight、意识 sense、操作 mech、英雄池 pool、心态 mental。旧草案的“团队”拆进团战和意识，“发育”并进对线（同时作为“后期发育”路线的成长方向）。
  - 性格层沿用旧草案 8 项（嘴硬、心态倾向、胜负心、逆风意志、创新欲、话痨、摸鱼倾向、甩锅倾向），基本固定。
  - 状态层：体力、心情、专注、手感、饥饿，加上疲劳、压力。
  - 另有位置适性（4.2）、潜力、特性。
- 初始数值【待定】：按 7 属性重新换算旧草案第 4 节的数字，等详细人设确认后定。

### 5.2 训练路线【已定】
- 每名队员选**一条长期发展路线**：对线压制、后期发育、游走节奏、团战核心、指挥大局、绝活专精、万金油。
- 路线和队员底子的适配度只显示**三档：S / A / B**【已定】，成长倍率建议 ×1.3 / ×1.0 / ×0.7。
- **改路线有一周磨合期**：成长变慢，心情下降。
- 训练产出“训练心得”（用途和数值见第 11 章）。
- **路线 → 属性【已定】**：每条路线 1 个主属性（成长 ×2）+ 1 个副属性（×1.3），其他属性 ×0.6；万金油没有主属性，全部 ×1.0。路线练到头解锁一个路线特性。
  | 路线 | 主属性 ×2 | 副属性 ×1.3 | 练成特性 |
  |---|---|---|---|
  | 对线压制 | lane | mech | 对线杀手 |
  | 后期发育 | mental | fight | 翻盘王 |
  | 游走节奏 | roam | sense | 节奏发动机 |
  | 团战核心 | fight | mech | 团战收割 |
  | 指挥大局 | sense | mental | 指挥官（全队加成） |
  | 绝活专精 | mech | lane | 绝活英雄 |
  | 万金油 | — | 全部 ×1.0 | 哪都能补（位置适性提升） |
- 最终成长倍率 = 路线倍率 × 适配度（S/A/B）× 当天专注与手感。
- **适配度计算【已定】**：看路线主属性在这个人 7 项属性里的排名，前 2 → S，前 4 → A，其余 → B。性格可以把档位上调一档，例如创新欲 ≥80 时绝活专精 +1 档，话痨 ≥70 时指挥大局 +1 档（对照表等人设确定）。属性成长后档位会跟着变。万金油按平均分判定。
- **练成判定【已定】**：主属性突破 70 瓶颈后，之后每场比赛有一定概率触发“开窍”名场面，特性当场解锁。

## 6. 日常玩法
### 6.1 日常循环【已定】
- 队员按作息自动训练、摸鱼、社交、吃饭。**摸鱼、甩锅自动发生**，不需要玩家触发。
- 遇到**重要事件**时弹窗，让老板选择处理方式。
- 老板可以随时使用**老板动作**（6.2）。

### 6.1.1 训练日自主行为与场景物件【已定】
- 非比赛日像 QQ 宠物式养成：每个队员按性格有**自主行为**，例如爱摸鱼、看手机、在电脑上看直播、下午犯困午休等。
- 场景里的**物件可以交互**：去饮水机喝水、开冰箱拿饮料、偶尔去零食柜吃零食等。队员走过去、使用物件，都要有动画，营造生活感。
- 自主行为由性格倾向和当前状态（体力、心情、专注、饥饿）共同驱动，可以触发事件看板条目和人物互动（例如两个人在冰箱前抢最后一瓶饮料）。

**示例：自主行为 × 性格倾向（示例，非最终，等详细人设到后再定）**
| 自主行为 | 主要驱动 | 偏向的人（按现有简要人设推测） |
|---|---|---|
| 摸鱼刷手机 | 摸鱼倾向高、专注低 | 待人设确认 |
| 在电脑上看直播（“复盘”） | 摸鱼倾向、话痨 | 待人设确认 |
| 下午午休趴桌睡 | 体力低，爱睡觉的性格 | 待人设确认 |
| 研究怪出装 | 创新欲高 | 施颠 |
| 找人闲聊“如何评价” | 话痨 | 地鼠 |
| 认真单排加练 | 胜负心高、专注高 | 待人设确认 |
| 起身溜达串工位 | 心情高、话痨 | 待人设确认 |

**示例：可交互物件（示例）**
| 物件 | 交互 | 影响 / 可能触发的小事件 |
|---|---|---|
| 饮水机 | 喝水 | 体力小回复；排队闲聊 |

| 窗边 | 发呆、打电话 | 心情变化 |

### 6.2 老板动作【已定方向，数值待定】

| 请奶茶 | 花小钱，全员心情小涨 | 谁先抢到、谁被漏掉会引出小事件（比如施颠又被忘了） |
| 单独谈话 | 免费，安抚、鼓励或敲打一个人 | 效果看性格，嘴硬的人可能越说越倔 |
| 调解矛盾 | 只在有心结时能用 | 成功：心结解开、交情上升；失败：两人一起对老板不满 |

### 6.3 防刷限制【已定】
1. **每日行动点【已定】**：随场地 **3 → 4 → 5 → 6**，比赛日额外 +1。每个动作都要消耗。
2. **对同一个人的冷却**：同一个人单独谈话要隔 2–3 天；团建、放假这类全员动作按周冷却。
3. **效果递减，用多了会反噬**：一周内请太多次奶茶，大家就觉得理所当然了；天天找同一个人谈，他会嫌烦，其他人会说老板偏心。
   - **递减曲线【已定】**：按滑动 7 天统计同一动作（对个人的动作按“动作 × 对象”统计），第 1 次 100%、第 2 次 70%、第 3 次 40%、第 4 次起反噬（效果变负，并触发“老板又来了”类事件）。
- 每个动作消耗几点、具体冷却几天【待定】，做数值时调手感。

### 6.4 日常小事件：点外卖【已定】
- 饭点时，个别队员会点外卖。一个**穿黄色美团外卖服的外卖员小人**会走进场地，把外卖送到对应工位（需要一套外卖员模型和走位动画）。
- 外卖品种要丰富，例如黄焖鸡、螺蛳粉、麻辣烫、猪脚饭、炸鸡、奶茶等，可继续扩充；可以和人设挂钩，做成每个人的“本命外卖”（详细人设到后再配）。
- 这是交互小事件，可以连锁，例如：
  - **螺蛳粉**：外卖一开，全场抗议，开窗、捏鼻子，有人在群里发起投票。
  - **蹭外卖**：有人去蹭别人的外卖，引出护食、分享、交情变化。
  - **送错 / 洒了 / 超时**：引发群聊吐槽、甩锅（“谁写的地址”），超时可能影响下午的心情和专注。
- 可以和“请奶茶”老板动作、饥饿状态联动。- **付钱【已定】**：默认队员自己付，不花公司钱。老板可以用“今天我请”（老板动作，花现金、全员心情小涨），场地设施“公司餐补”可以把它变成长期开支 + 心情加成。
- **频率【已定】**：午饭和晚饭每人独立判定要不要点，平均每个饭点 2–3 人点；懒、饿的人更爱点。每单约 15% 触发连锁（螺蛳粉抗议、蹭外卖、送错 / 洒了 / 超时），同一种连锁冷却 3 天。
- 外卖品种、效果和连锁草案见 `docs/外卖表-草案v0.1.md`。本命外卖【待定】。

### 6.5 事件看板【已定】

- 分级【沿用】：日常 / 有趣 / 剧情 / 重大。重大事件置顶，有的会触发自动暂停。
- 事件素材：`docs/事件库-v0.1.md`（227 条事件、18 条连锁）、`data/events.json`、`tools/gen.py`（采用 Claude 修复的“/”拆分版本）。改造要求：
  - 删掉“天意 / 管理员”类，或把它改造成老板动作的结果；
  - “监督 / 举报”类改成老板视角，或保留为队员之间的玩闹；
  - 调整文案，不能和温暖基调冲突（见第 7 章）；
  - 位置相关的事件按 4.1 修正。

## 7. 人物关系系统【已定】
- **交情只升不降**：每两人之间有一个交情值，只会慢慢变好，不会变成仇人。甩锅、互损也算交情的一部分，被甩锅最多的施颠反而可能和大家最铁。
- **小心结是临时的**：吵架、被甩锅、被批评会给两人挂上一个临时“小心结”，几天后自己淡掉，也可以被事件、双排、老板调解提前化开。
- **心结带进比赛日才有影响**：比赛当天两人的心结还在，他们之间的配合打折扣，直播里也有对应台词，比如“打野又没来抓上”。
- **赢球化解一切**：赢了比赛全队氛围上涨，心结有很大概率当场解开，并触发赛后庆祝事件。**输了心结不会加重**，最多多一轮赛后甩锅群聊。
- **高交情解锁奖励**：专属事件、默契连招（比赛加成）、名场面。
- **交情档位【已定】**（0–100）：
  | 阈值 | 档位 | 解锁 |
  |---|---|---|
  | 0 | 同事 | — |
  | 20 | 队友 | — |
  | 40 | 朋友 | — |
  | 65 | 好兄弟 | 专属事件、名场面 |
  | 85 | 铁哥们 | 默契连招（比赛加成） |
  开局 6 人之间大多在 30–55；施颠被甩锅多，交情涨得最快。
- **心结数值【已定】**：一个心结持续 3 天；比赛中两人配合 −8%；同一对人最多叠 2 个（−15%）。
- **默契连招【已定】**：6 人共 15 对，每对一个专属、有名字的连招（例如“当邓施颠·甩锅不过三”）。两人达到铁哥们并且同时首发时，比赛中相关节点 +6%，并有专属解说台词。连招名字和台词等人设到了再写。
- 数据建议：`relations[a][b] = { bond: number, knots: [{cause, expireDay}], unlocked: string[] }`，可附加“甩锅对象”这类专属标签。

## 8. 比赛日【已定】
- 比赛日自动暂停。老板只做两件事：**选首发 5 人**，**选战术**。然后观看直播。
- **开赛时间【已定】**：比赛日 19:00 开打。白天是赛前准备（紧张、嘴硬、干饭），赛后庆祝或甩锅群聊一直到下班。
- **局数【已定】**：网吧联赛 BO1；城市联赛起 BO3。BO3 局间可以换首发和战术。
- **没有 BP，没有局内决策节点。**
- 引擎沿用灵感版思路（`inspiration/电竞经理/开发手册.html`）：
  - 种子随机 `makeRng`，同一种子得到同一结果，可复现、可对账；
  - 时间轴节点：节点类型 × 属性权重 → 击杀、推塔产出，逐杀记账，有经济、提前 GG、膀胱局延长；
  - 7 属性 + 位置适性 + 潜力 + 特性；
  - 战术五环克制：强开团 > 保排消耗 > 防守反打 > 速攻节奏 > 运营发育 > 强开团，克制方节点 ×1.05；
  - 疲劳、压力；
  - 回归测试（KDA 对账、直播和计分板对账、胜率曲线目标带）。
- 本作新增的接口：心结削弱相关两人的配合；高交情默契连招加成；赛后事件接入本作的事件系统（灵感版 31 个赛后事件可改编）。
- 灵感版特性（吊儿郎当、缚地魔、对线指挥官、顺逆风心态等）可参考，改编成本作人设特性【待定】。
- 直播文风延续“体育解说 + 队员群聊”。
- **开局战术【已定】**：开局只有强开团、运营发育 2 个，其余 3 个各花 200–400 心得研究解锁。和人设挂钩的特殊战术（如施颠的发明流奇袭）作为额外研究项。

## 9. 联赛【已定】
| 项目 | 规则 |
|---|---|
| 层级 | 网吧联赛 → 城市联赛 → 国内联赛；世界赛是资格赛事 |
| 规模 | 每级 8 队，双循环，一个赛季 14 轮 |
| 频率 | 每 2 个游戏日一场，一个赛季约 4 周（正常速度下现实约 4.5 小时，快档约 1.5 小时） |
| 升降 | 前 2 名升级，后 2 名降级 |
| 世界赛 | 国内联赛前 2 名 + 6 支海外队，共 8 队**单败淘汰 BO3**（八强、半决赛、决赛），每 2 天一场，约一周 |
| 休赛 | 赛季间 1 周：搬家、换路线、谈赞助（招新人留给 DLC） |
| 网吧联赛垫底 | **不降级**（没有更低的级别）：少拿奖金、赞助商不满，并触发“被包夜大叔队羞辱”之类的搞笑事件 |
| 对手 | **全部虚构**。网吧、城市联赛纯搞笑（隔壁包夜大叔队、小学生战队…）；国内和世界赛用真实战队的谐音或改编，避免侵权。每队 5 个人名 + 1 个特色 |

- **对手实力【已定】**：每级联赛 7 支对手分布在一个能力区间内，其中 1 支明显的强队、1 支弱队；对手每个赛季也会小幅成长，升降级的队伍在联赛之间流动。
  | 联赛 | 对手能力均值 |
  |---|---|
  | 网吧 | 35–52 |
  | 城市 | 48–63 |
  | 国内 | 60–76 |
  | 世界赛 | 72–88 |
  预期节奏：开局 6 人均值约 45，第 1 赛季网吧联赛中游，第 2–3 赛季升城市，大约 12–20 个赛季拿到世界赛冠军。
- 对手名单草案见 `docs/对手名单-草案v0.1.md`（27 支队，含队名、人名、战术、特色）。

## 10. 场地升级【已定】

- **降级不强制搬家【已定】**：场地保留，但奖金和赞助变少、房租照交，经济压力变大。老板可以主动“退租搬回去”，拿回部分费用。

- **费用【已定，草案数值】**：

  | 电竞基地 | 120,000 | 18,000 | 40% |

  搬家费约等于当前联赛 2–3 个赛季的结余，搬过去后的第一个赛季大概率小亏。

  | 电竞基地 | 复盘室 15,000、健身角 10,000、按摩椅 8,000、咖啡机 4,000 |
  | 豪华基地 | 私人厨师、游戏房、直播间（解锁开播赚钱） |
- **设施加成规则【已定】**：恢复类加体力 / 心情，训练类加心得 10%–20%，每件设施配 1–2 个小事件。具体数字和豪华基地设施价格等原型跑起来后在 M4 调。
