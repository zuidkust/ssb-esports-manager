# 美术：像素街区画风 v1（对标《Corner Pitch》）

> 日期：2026-10-24 · 分支：`art/corner-pitch-style`（基于 `cursor/pixel-pipeline-phase1-206d`，后者基于 `main @ f6428f0` v0.5）
> 参考：小红书视频《Corner Pitch》（Three.js 单 HTML 文件，3v3 街头笼式足球）。视频字幕给出的做法：**低分辨率渲染 + 调色板量化 + 深度描边**。
> 范围：只改画面，不改玩法、数值、存档。

截图见 `docs/像素街区画风-截图/`（白天 / 黄昏 / 夜晚 / 暴雨 / 电竞基地）。

---

## 1. 拍板

| 项 | 结论 |
|---|---|
| 画风 | 跟视频一致：等距正交镜头、低分像素、外轮廓描边 + 朝外棱提亮、平直着色低多边形、浅灰背景上的漂浮街区 |
| 人物比例 | **跟视频走：正常比例小人**（头身约 1:5.6），替换方块大头手办。用户 2026-10-24 明确要求“人与物比例和视频保持一致” |
| 认人 | 保留六人的识别特征：衫色、发型、眼镜（当邓发光青镜片、阿鸡粗黑框）、阿鸡人字拖、撇干挂脖红耳罩和黑眼圈；高矮胖瘦（当邓最矮、弟必最高、撇干最壮）不变 |
| 内容 | 不搬足球场。网吧 / 办公室房间坐在一块漂浮街区上，外面是人行道、树、路灯、砖楼 |
| 天气 | 加暴雨，纯画面。约四分之一的日子下雨，同一天固定 |

## 2. 视频要素 → 实现

| 视频里的 | 本分支 | 文件 |
|---|---|---|
| 低分辨率渲染 | 粒度按 **CSS 像素**算（默认 4，可选 3 / 5），Retina 屏颗粒不变细；窄屏自动收小，保证约 200 列 | `scene/pixelPass.ts` |
| 调色板量化 | 每通道 32 级 + 很轻的 4×4 Bayer（只在渐变处出颗粒），轻微提饱和 ×1.1 | `scene/pixelPass.ts` |
| 深度描边 | 邻居明显更远（> 0.22 m）→ 压暗**物体自身**的边缘像素（保留色相，不是统一黑线） | `scene/pixelPass.ts` |
| 棱边高光 | 同一表面附近、法线拐过去的凸棱提亮 | `scene/pixelPass.ts` |
| 浅灰背景 | 合成时给深度 = 1 的像素填渐变；昼夜只微调，下雨压暗成阴天灰 | `pixelPass.ts`、`lighting.ts` |
| 漂浮城市街区 | 草皮顶面 + 草皮侧面 + 土层 + 一圈近乎垂直的岩壁，再一层层收成尖底；岩面逐面随机灰度 | `scene/diorama.ts` |
| 人行道、路缘石、柏油 | 世界坐标 UV 的像素贴图（一个贴素约 7 cm） | `diorama.ts`、`textures.ts` |
| 树、灌木 | 二十面体叶团（平直着色），灌木篱是方块 | `diorama.ts`、`office.ts` |
| 路灯 + 实时阴影 | 3 盏路灯（聚光灯），前排中间那盏投影；傍晚 / 下雨开灯 | `diorama.ts`、`lighting.ts` |
| 街角砖楼、亮窗 | 后墙右侧 7 m 砖楼，约一半窗户夜里亮；侧面竖招牌“网吧”；屋顶水箱、空调外机 | `diorama.ts` |
| 硬阴影、日夜 | `BasicShadowMap` 硬边；太阳强、天光弱；太阳轨迹在场景里转 90°，影子一整天都落在镜头看得见的一侧 | `lighting.ts` |
| 暴雨、溅水、场地变湿、积水 | 雨丝只落在室外（房间没有天花板，室内不能淋雨）；落地溅水花；地面随雨变深变光滑，人行道显出积水 | `scene/weather.ts` |
| 小人 | 方块拼装真人比例：短袖 T 恤 + 短裤 + 露小腿 + 白袜 + 鞋，约 19 个低分像素高（视频约 18） | `scene/character.ts` |
| 原始 3D 对照 | 保留 PIXEL / RAW 3D 按钮和 `?raw3d=1` | `main.ts` |

另外：

- **低多边形化**：`rbox` 小于一个低分像素的圆角改直角盒；圆柱 / 车削体最多 8 段；材质统一平直着色。
- **静态合批** `scene/merge.ts`：同一父节点下、材质相同的叶子网格合成一个。会动的组（椅子、显示器、门、冰箱门、人物关节）保留，组内各自合并；钟的指针、拾取柱、杯子不合。
- **房间配色**：网吧改成奶油色墙 + 深青墙裙 + 米白地砖，在绿草地、红砖楼中间跳出来。
- **HUD**：浅灰背景上，品牌和时钟各自垫一块深色方块；面板改小圆角 + 硬投影。顺手修了窄屏顶栏被 `#topbar { right: 420px }` 挤成一条的旧问题。

## 3. 关键参数

```
镜头          正交，方向 (1, 0.82, 1)（约 30° 俯角、45° 方位），视锥高 17.5，可见宽 ≥ 24.5
像素粒度      默认 4 CSS 像素；窄屏 max(2, min(选择, 可见宽 / 200))
描边          深度落差 > 0.22 m 压暗到 52%；凸棱提亮 ×1.32
量化          32 级/通道，Bayer 幅度 0.8 级；饱和 ×1.1
岛体          x ∈ [-8.5, 9.1]，z ∈ [-7.5, 7.1]；顶面 y = -0.04，尖底约 y = -5
人物          身高 1.72 × height；头 0.23×0.26×0.24 + 发 ~0.05；腿 0.84；坐高 0.5
雨            1100 根雨丝；前、右两条人行道的雨从 3.4 m 落（防止投影盖到房间里），其余从 9 m
```

- 像素模式多一个法线 pass，但法线 pass 不重画阴影、不画雨；灯灭时它的阴影贴图不更新。
- 测试 185 项全过（新增静态合批、天气排程、窄屏粒度）。

## 5. 没做 / 后续

| 项 | 说明 |
|---|---|
| 一键旋转视角 | 视频有。房间后墙、左墙是 3 米高墙，转到别的方位需要墙体自动剖开，砖楼也会挡住房间；工作量中等，单独排 |
| 真·积水倒影 | 现在积水是低粗糙度材质反射环境光，夜里能反路灯高光；真倒影要再加一个平面反射 pass |
| 像素字体 UI | 视频的 HUD 是像素字体。不能引外部字体，中文像素字体要自己做位图，先不动 |
| 室内细节的像素化 | 键盘、杯子这类小物件低分下只剩一两个像素，后续可按“低分下能读出来”的尺寸重做一批道具 |

## 6. 怎么看

```bash
cd game && npm run build
# 默认 PIXEL；?raw3d=1 原始 3D；?pixel=3|4|5 粒度；?rain=1 强制下雨，?rain=0 强制晴天
node scripts/screenshots.mjs 't=14:30&day=3&paused=1&rain=1'
```

控制台：`__ssb.setRain(1)` 下雨，`__ssb.setRain(null)` 回到按天数决定。
