# 成长属性体系 · 草案 v0.1

## 1. 属性分三层
### A. 能力（长期，缓慢成长，0–100）
| 属性 | 含义 | 主要影响 |
|---|---|---|
| 操作 | 补刀、技能命中、对拼 | 对线、团战输出 |
| 意识 | 视野、地图理解、支援时机 | 节奏、少犯错 |
| 对线 | 线上压制与抗压 | 前期优势 |
| 发育 | 逆风偷经济、后期能力 | 翻盘概率 |
| 团队 | 沟通、指挥、配合 | 组排与比赛加成 |
| 英雄池 | 会玩的英雄数量与熟练度 | 选人、被针对时的弹性 |

### B. 性格（基本固定，只在重大事件后微调，0–100）
嘴硬、心态、胜负心、逆风意志、创新欲（发明流）、话痨、摸鱼倾向、甩锅倾向。

### C. 状态（每天波动，0–100）
体力、心情、专注、手感、饥饿。每天早上按睡眠与前一天心情重置一部分。

## 2. 成长规则
- 能力只靠"有效练习"增长：认真单排、组排、复盘、比赛。摸鱼时间不增长。
- 每次练习获得经验，越高越难涨（边际递减）；当天专注和手感是倍率。
- 一局里被打爆、被骂也能涨对应属性，但可能扣心情。
- 段位是结果，不是属性：由近期胜率和隐藏分推算，约每周可能升/降一个小段。

## 3. 进化方向（每人一条主路线，按概率偏向，不是锁死）
| 成员 | 进化方向 | 成长偏向 | 天花板倾向 |
|---|---|---|---|
| 施颠 | 发明流大师 | 创新欲高，英雄池涨最快，操作慢 | 可能偶尔把怪套路练成真绝活 |
| 当邓 | 嘴硬打野到逆风核心 | 意识、操作稳涨；逆风意志是成长关键 | 若逆风意志突破 60，触发"不投了"转变事件 |
| 地鼠 | 稳定输出天花板 | 操作、发育稳步涨，波动最小 | 最可能先到铂金 |
| 弟必 | 后期翻盘王 | 发育大幅领先，对线最难涨 | 对线若补上短板，成为全队最强 |
| 吊龙 | 指挥核心 | 团队、意识领先 | 组排加成随他提高，比赛中影响最大 |
| 批菊 | 嘴硬上单的觉醒 | 对线慢涨但受挫后会突然爆发一段 | 可能从被打爆转成抗压型上单 |

## 5. 比赛模拟里怎么用
队伍实力 = 五人能力加权（各位置权重不同）× 当天状态 × 团队配合 + 随机。逆风时用逆风意志和心态判定是否崩盘或翻盘；施颠有小概率触发"发明流奇袭"。
