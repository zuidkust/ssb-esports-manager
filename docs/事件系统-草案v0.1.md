# 事件系统 · 草案 v0.1

## 1. 事件分级
| 级别 | 频率（每个工作日全办公室） | 例子 | 事件板展示 |
|---|---|---|---|
| 日常 | 30–60 条 | 某人开了一局单排、去打水、点外卖 | 灰色小字，可折叠 |
| 有趣 | 8–15 条 | 摸鱼被抓、连跪红温、发明流出装翻车 | 正常条目 |
| 剧情 | 1–3 条 | 吵架、和好、举报包庇连锁、有人想退出 | 高亮卡片，带后续 |
| 重大 | 每周 0–2 条 | 比赛、段位晋升、性格转变、伤病 | 置顶，配插图或回放 |

## 2. 事件分类
1. **对局**：单排/组排胜负、高光、送人头、挂机、遇到演员、超神。
2. **摸鱼**：直播、刷手机、拼单奶茶、带薪如厕、午睡、开小号炸鱼、"如何评价"闲聊、"版本研究"。
3. **监督**：发现摸鱼 → 举报 / 包庇 / 拍照发群 / 拿来交换不被甩锅。
4. **甩锅与关系**：甩锅、反驳、阴阳怪气、和好、结成双排搭子；关系值随之变化。
5. **成长**：练出新英雄、属性突破阈值、段位升降、进化方向转折。
6. **生活**：早到、加班、迟到、请假、生日、请客、身体不舒服。
7. **比赛**：赛前讨论阵容、替补争夺、比赛文字直播、赛后庆功或复盘吵架。
8. **天意（管理员）**：外观与自然事件完全相同，只在后台日志可见。

## 3. 触发机制
- 每分钟对每个人按当前状态算一次"行为选择"（练习 / 摸鱼 / 社交 / 生活需求）。
- 事件由"条件 + 概率"触发，例：专注 < 30 且在单排排队 → 摸鱼概率 ×2。
- 性格放大器：甩锅倾向高的人在输局后更可能触发甩锅；话痨在休息时更可能开话题。
- 连锁：一个事件可以给后续事件加权，例如"摸鱼被拍"会在当天提高"报复举报"的概率。
- 冷却：同一类事件对同一个人有冷却时间，避免刷屏。

## 4. 事件板文案风格
- 像办公室群聊加体育解说的混合，短、具体、有梗，带时间戳。
- 示例：
  - `10:42` 施颠出了一套"全暴击石头人"，自称版本答案。
  - `10:58` 施颠 0/7/2。当邓："我就说吧。" 施颠："这是实验数据。"
  - `14:15` 地鼠："如何评价这把奶茶拼单少了我一杯？" 全屋停手讨论 18 分钟。
  - `15:30` 批菊对线被单杀三次，转头开始点评施颠的出装。
  - `16:05` 当邓第 3 次发起投降，吊龙拒绝；28 分钟后弟必发育起来，翻盘了。
- 每条事件可点开看参与者、前因后果和当时画面定格。

## 5. 文案生成方式（建议）
模板库保证稳定和量，配合大模型做少量润色和剧情事件的长文本；所有文本服务端生成后存库，旁观者看到的是同一份历史。
