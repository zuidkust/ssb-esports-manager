## 2. 谁更爱点（按性格和状态）
| 条件 | 点外卖概率修正 |
|---|---|
| 饥饿 ≥ 60 | +30% |
| 摸鱼倾向高 | +15% |
| 心情低 | +10%，偏向奶茶、炸鸡 |
| 欠薪 / 月底 | −20%，偏向泡面、沙县 |
| 比赛日赛前 | 偏向“稳”标签，避开螺蛳粉（阿鸡不挑，例外） |

## 3. 连锁事件（每单约 15% 触发，同类 3 天冷却）
| 连锁 | 权重 | 内容 | 影响 |
|---|---|---|---|
| 螺蛳粉抗议 | 只在点螺蛳粉时 60% | 全场抗议、开窗、群里发起投票 | 相关两人挂小心结，或交情 +1（吵完一起笑） |
| 蹭外卖 | 25 | 有人去蹭，引出护食或分享 | 分享：交情 +2；护食：小心结 |
| 送错 | 15 | 外卖员小人走错工位，被别人吃了 | 群聊追凶，甩锅“谁写的地址” |

| 超时 | 15 | 外卖员迟到 | 下午心情、专注下降；可能触发“催单”群聊 |
| 拼单 | 20 | 两人凑满减 | 交情 +1；谁付零头引出小争执 |
| 点重了 | 10 | 两人点了同一家 | 被说“心有灵犀” |
| 外卖员认出来了 | 5（城市联赛起） | “你们是那个战队？” | 全员心情 +3，赞助进度小涨 |

## 4. M2 实装说明（2026-10-22）
草案仍然是菜单来源。和实装不一致、又还没确认的地方：
- “今天我请”按本表单价从公司扣，不预扣设计文档旧表里的 200。
- 赛前晚饭其他人少点螺蛳粉。阿鸡不挑，权重不压。
- 本命和一句“这就是本命”已接上，见第 5 节。连锁文案仍是通用句子，名字只填点单的人。
- 疯狂星期四只加倍麦当劳 / 肯德基的权重，并多一句文案。
- 猪脚饭“犯困”记成疲劳 +10。
- 公司现金不够付整单时，整单改回自付。
