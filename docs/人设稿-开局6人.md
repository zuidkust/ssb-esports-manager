# 《SSB电竞经理》开局 6 人人设定稿

> 采集对象：阿鸡（原施颠）、当邓、狗粮（原地鼠）、弟必、吊隆（原吊龙）、撇干（原批菊）（真实朋友群）
> **游戏内正式名【定稿】**：阿鸡、当邓、狗粮、弟必、吊隆、撇干（2026-10-22 用户确认改名）  
> 采集完成日期：2026-10-22（Asia/Shanghai）  
> 用途：驱动非比赛日自主行为、交情与事件、比赛日台词与解说调侃、老板动作反馈等。  
> 说明：本文件由人设采集确认整理，不编造事实。默契连招暂未取专名。  
> **补充（2026-10-22）**：撇干绝不玩石头人。队伍希望上路能开团，尤其想让他拿石头人，他拒绝，选人时从不拿。

## 1. 阿鸡（原施颠）

### 基本面
| 项 | 内容 |
|---|---|
| 主位置 | 上单、打野（五个位置都能打，安心补位） |
| 擅长 | 英雄池、心态 |
| 拉胯 | 意识、操作 |
| 招牌英雄 | 上单克烈、打野猪妹（都是绝活） |
| 风格 | 体系工具人；爱搞野路子出装；队里的笑点和背锅侠，心态好 |

### 性格与台词
- **性格关键词**：乐天派；脑回路清奇；脸皮厚不记仇；嘴硬自信；好脾气好说话；爱研究别人不玩的东西
- **口头禅**：「我要拿出我的兜裆布了」（连跪后掏克烈）；用歪理论为自己的出装辩护
- **输了**：一笑了之马上忘掉；嘴硬甩锅；主动认错说「下把我的」；嚷着再来一把；要拿克烈报仇
- **赢了**：立刻邀功说出装赢的；得意证明歪理论对了；反复回放自己高光
- **压力/被批评**：先歪理论，再认错，再用自嘲化解
- **现实补充**：抽烟；有老婆有孩子

### 日常习惯（自主行为）
- **摸鱼**：抽烟；刷手机；研究歪出装；午睡；吃零食；偷偷玩 Steam 单机和三角洲
- **作息**：大体早睡早起（照顾孩子），随家庭安排不固定
- **本命外卖**：不挑，什么都吃（随机点单）；无讨厌的食物
- **饮料 / 零食**：可乐汽水；零食不挑
- **奶茶**：不喝，换成可乐
- **手机**：抖音短视频；无特别爱看的主播

### 比赛与经理视角
- **关键局**：跟平时一样不受影响；关键局必上克烈
- **解说调侃**：「这个出装我解说了十年没见过」；「阿鸡又在开发新打法了」；「这波锅估计又是阿鸡的」；「五个位置哪里都能撑，哪里都能崩」
- **怎么哄**：表扬他的出装或打法
- **雷点**：几乎没有

## 2. 当邓（外号：出装警察）

### 基本面
| 项 | 内容 |
|---|---|
| 主位置 | 打野（副：上单） |
| 擅长 | 游走、团战、意识 |
| 拉胯 | 英雄池、心态 |
| 招牌英雄 | 打野雪人、凯隐；上单牧魂人 |
| 风格 | 节奏大师，全图带节奏；团战指挥开团时机；顺风浪逆风崩，上限看心态；只会几个招牌，被 ban 就懵 |

### 性格与台词
- **性格关键词**：爆脾气急性子；爱指挥爱操心；好胜心强；嘴硬不服输
- **常说的话**：赖线上被压导致野区被入侵；当出装警察点评别人装备；早没优势就喊投降；怪队友不来野区打架、不听指挥所以落后
- **输了**：复盘怪队友不听指挥；说「早说投了」
- **赢了**：说是自己节奏带得好；点评别人出装；说「就该这么打」
- **压力/被批评**：当场急眼对喷，把锅甩回队友

### 日常习惯（自主行为）
- **摸鱼**：刷手机；跑去指点别人训练；午睡；吃零食
- **作息**：不固定
- **本命外卖**：汉堡炸鸡；无讨厌的食物
- **饮料 / 零食**：红牛、东鹏，也喝无糖系饮料；零食不挑
- **奶茶**：跟大家一样，没偏好
- **手机**：抖音、B站、水群；无特别爱看的主播

### 比赛与经理视角
- **关键局**：容易紧张失误；顺风还稳，一落后就上头
- **解说调侃**：「出装警察又在查队友的装备了」；「三分钟没优势，当邓要发起投降了」；「野区被入侵，线上又要挨骂了」；「雪人一推球，又是他的节奏」；「顺风是指挥官，逆风是指责官」
- **怎么哄**：表扬他的节奏和指挥
- **雷点**：指挥没人听；野区被入侵没人帮忙；拿手英雄被 ban；当面批评；队友乱出装

## 3. 狗粮（原地鼠）

### 基本面
| 项 | 内容 |
|---|---|
| 主位置 | 下路 ADC（只玩 ADC） |
| 擅长 | 团战、操作、英雄池 |
| 拉胯 | 没有明显短板 |
| 招牌英雄 | 主流 AD 都会，除了德莱文、滑板鞋、厄斐琉斯 |
| 风格 | 团战收割机；安静发育后期 Carry；极限反杀秀操作；队伍最后保障；话很多 |

### 性格与台词
- **性格关键词**：话痨停不下来；靠谱稳重；爱吐槽爱说骚话；乐天好相处
- **常说的话**：嘲讽对面；失误时自责；嘲笑阿鸡和撇干
- **输了**：先自责；自嘲着吐槽队友；嘲笑阿鸡或撇干的失误；很快翻篇
- **赢了**：狂嘲对面；炫耀极限操作；夸队友顺便损两句；话比平时更多
- **压力/被批评**：乐于认错（「是我的」「my bad」）；自嘲化解；嘴上认了再损回去

### 日常习惯（自主行为）
- **摸鱼**：刷手机；找人闲聊吹牛；去损阿鸡或撇干；午睡；吃零食
- **作息**：早睡早起
- **本命外卖**：汉堡炸鸡；无讨厌的食物
- **饮料 / 零食**：无糖饮料、茶水、白开水；薯片膨化食品
- **奶茶**：跟大家一样，没偏好
- **手机**：抖音短视频、水群；无特别爱看的主播
- **游戏习惯**：容易累，经常打两三把就不打，有时只上一把就称累了（群梗：「记住了，我只玩一把」）

### 比赛与经理视角
- **关键局**：看状态——有时大心脏越关键越稳，有时紧张失误（随机）
- **解说调侃**：「狗粮的嘴和他的输出一样停不下来」；「又反杀了，对面要被嘲一整局了」；「队伍最后的保障，也是最吵的保障」；「打完这波，阿鸡又要被他损了」
- **怎么哄**：表扬他的操作和输出
- **雷点**：被对面特殊照顾针对导致劣势

## 4. 弟必（外号：葛永、小必、大标）

### 基本面
| 项 | 内容 |
|---|---|
| 主位置 | 中单（只玩中单） |
| 擅长 | 团战、心态 |
| 拉胯 | 对线、英雄池 |
| 招牌英雄 | 维克托、小法师、阿罗拉等法核；也喜欢玩薇古丝 |
| 风格 | 对线忍耐，团战发力；稳定输出的后排法师；心态好，逆风不放弃；不游走，喜欢赖线，不擅长支援（群称「缚地魔」） |
| 克制弱点 | 最怕刺客（对线必爆炸）；尤其怕永恩 |

### 性格与台词
- **性格关键词**：佛系淡定；耐心好脾气；靠谱稳重；闷骚偶尔出金句；乐天好相处
- **说话**：比较平常，没有固定口头禅
- **输了**：淡定说「没事，下一把」；吐槽对面刺客；也会自责反思
- **赢了**：闷骚冒一句金句；夸队友打得好；团战打爆了会小小得意一下
- **压力/被批评**：淡定接受，默默改；先自责，再找原因
- **其他**：也爱玩三角洲

### 日常习惯（自主行为）
- **摸鱼**：刷手机；玩三角洲
- **作息**：很正常，不特别早起也不特别熬夜
- **本命外卖**：汉堡炸鸡；不挑；无讨厌的食物
- **饮料 / 零食**：可乐/碳酸，茶水/白开水；薯片膨化
- **奶茶**：跟大家一样，没偏好
- **手机**：抖音、水群、三角洲相关内容；无特别爱看的主播

### 比赛与经理视角
- **关键局**：跟平时一样，不受影响
- **解说调侃**：「对线被打成这样，团战照样输出拉满」；「又碰到刺客了，弟必的对线要爆炸了」
- **怎么哄**：表扬他团战输出
- **雷点**：对线被刺客打爆；拿手英雄被 ban；队友不等他就开团

## 5. 吊隆（原吊龙）

### 基本面
| 项 | 内容 |
|---|---|
| 主位置 | 辅助（只玩辅助） |
| 擅长 | 对线、团战、意识 |
| 拉胯 | 游走 |
| 招牌英雄 | 锤石、机器人等带钩子的硬辅；软辅不太擅长 |
| 风格 | 钩子一中就开团的进攻型辅助；对线压制，带着 AD 打线权；意识好；团战前排开团或保人；只守下路，很少游走 |

### 性格与台词
- **性格关键词**：靠谱担当；温和好相处；毒舌爱怼人
- **常说的话**：经常点评其他线和打野队友线上打得好坏；自己对线时也经常指挥各路队友做事
- **金句机制**：闲暇之余给人取无厘头外号，标准句式「XX最新外号，XX」；外号可由系统生成一批荒诞搞笑、让人摸不着头脑的名字
- **输了**：复盘点评每路哪里打崩了；毒舌怼队友；冷静接受，下一把
- **赢了**：点评谁打得好谁划水；说这把是他钩子开出来的；顺便毒舌一下对面
- **压力/被批评**：毒舌反怼回去；把锅甩给 AD 或打野

### 日常习惯（自主行为）
- **摸鱼**：刷手机；午睡
- **作息**：不规律
- **本命外卖**：汉堡炸鸡；不挑；不吃内脏
- **饮料 / 零食**：咖啡；不怎么吃零食
- **奶茶**：跟大家一样，没偏好
- **手机**：抖音、B站、水群、看比赛/电竞资讯、小说/新闻；无特别爱看的主播

### 比赛与经理视角
- **关键局**：大心脏，越关键越稳；跟平时一样；关键局指挥更多
- **解说调侃**：「钩子一中，这波又是吊隆开出来的」；「辅助从不离开下路，地图其他地方是什么？」
- **怎么哄**：表扬他钩子和开团；表扬他的指挥和点评；放假
- **雷点**：拿手英雄被 ban
- **外号**：暂无个人固定外号

## 6. 撇干（原批菊）

### 基本面
| 项 | 内容 |
|---|---|
| 主位置 | 上单（只玩上单） |
| 擅长 | 没有特别擅长的方面 |
| 拉胯 | 对线、英雄池、心态 |
| 招牌英雄 | 主玩战士类上单，成名英雄剑魔（群称「剑魔人柱力」，拿剑魔战力 +30%）。**绝不玩石头人** |
| 英雄池 / 禁用偏好 | 池子窄，招牌是剑魔。队伍希望上路能开团，首选石头人，BP 时希望把石头人留给他；他拒绝，选人时从不拿。石头人不进他的英雄池，也不算他的禁用请求——是队伍想留、他偏不选 |
| 风格 | 战士硬刚，剑魔开大就冲；对线容易崩，团战看运气；心态一炸整局炸；英雄池窄；经常送，对线英雄变成对局 MVP；打法激进爱干架，经常掌握不好时机被反杀或被打野蹲到，就此一蹶不振。让他拿石头人开团，他直接换回剑魔 |

### 性格与台词
- **性格关键词**：容易上头炸心态；爱甩锅；经常把对线期劣势归结于敌我打野差距，暗示自己被对面针对
- **口头禅**：「对面什么打野啊，3分钟来一次，5分钟又来一次」之类
- **输了**：怪对面打野针对自己；怪自家打野不来；心态炸了不说话
- **赢了**：说自己对线打爆了；说剑魔开大 carry 了；邀功说这把靠上路；喷对面打野帮都帮不起来
- **压力/被批评**：说自己被针对；闷着不说话

### 日常习惯（自主行为）
- **摸鱼**：刷手机；吃零食
- **作息**：爱熬夜
- **本命外卖**：不挑，什么都行；无讨厌的食物
- **饮料 / 零食**：可乐/碳酸；薯片膨化、辣条
- **奶茶**：跟大家一样，没偏好
- **手机**：抖音、B站、水群、看比赛/电竞资讯、小说/新闻、小红书；无特别爱看的主播

### 比赛与经理视角
- **关键局**：容易紧张失误；心态更容易炸；对线一炸就全场隐身，把对面上单养成大爹
- **解说调侃**：「又在喊对面打野三分钟来一次了」；「对线送成这样，对面上路要成大爹了」；「剑魔开大冲进去了，能不能回来另说」
- **怎么哄**：表扬他剑魔和上路；安排打野多帮他
- **雷点**：被对面打野针对；自家打野不来上路；拿手英雄被 ban；被人说对线送；关键局被批评
- **外号**：暂无

## 7. 人际关系与团队角色

### 交情与互怼

| 关系 | 说明 |
|---|---|
| 最铁 | 阿鸡↔当邓；狗粮↔吊隆（下路）；弟必↔阿鸡；整体六人都差不多铁 |
| 互怼 | 当邓↔阿鸡（出装警察 vs 野路子出装）；狗粮损阿鸡、损撇干；当邓↔撇干（打野帮不帮）；无论谁打上单都会被其他人指指点点 |
| 甩锅 | 撇干、当邓 |
| 背锅 | 阿鸡（常客）、撇干也会背 |

### 团队角色

| 角色 | 人选 |
|---|---|
| 开心果 | 阿鸡 |
| 指挥 | 当邓、吊隆 |
| 和事佬 | 弟必 |

### 名场面 / 黑历史
1. **奇迹团**：SSB 擅长整场被压制后靠一波团战翻盘，经常上演。
2. **阿鸡猪妹大赛**：阿鸡在大赛上用猪妹打野打爆对面，三路节奏带飞，留下很多名场面。
3. **撇干干架翻车**：上路激进爱干架，经常时机不对被反杀或被打野蹲到，就此一蹶不振（经常发生）。

### 默契连招（暂不取专名）

| 组合 | 位置搭配 | 连招名 |
|---|---|---|
| 狗粮 ↔ 吊隆 | 下路 AD + 辅助 | 暂无 |
| 弟必 ↔ 当邓 | 中野 | 暂无 |

### 事件系统可用梗（备忘）
- 阿鸡野路子出装 ↔ 当邓出装警察
- 狗粮嘴不停，损阿鸡 / 撇干
- 吊隆「XX最新外号，XX」无厘头外号生成
- 撇干「对面打野三分钟来一次」与当邓帮不帮上路的拌嘴
- 队伍想要开团上单、尤其石头人；撇干拒绝，从不拿石头人
- 弟必遇刺客 / 永恩对线必炸；赖线不游走
- 吊隆被批评甩锅给 AD（狗粮）或打野（当邓）
