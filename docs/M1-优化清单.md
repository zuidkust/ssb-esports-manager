# M1 优化清单（交给 Claude Code 实施）

依据：`docs/SSB电竞经理-设计文档-v0.3.md` + M1 试玩审查（2026-10-22）。改完请同步更新设计文档对应条目。

## 一、【用户已拍板】开局场景：新做「网吧角落」
- 新建简陋网吧场景作为开局场地：一排网吧机位（6 台，椅子破旧）、墙上网吧招牌/价目表、旁边有其他路人网民、网管吧台、饮水机（唯一自带设施）。
- 没有沙发、冰箱、零食柜、懒人沙发；午睡只能趴桌；零食需购买零食柜（800）后才出现。
- 现有办公室场景保留，作为「小办公室」（打到城市联赛并付搬家费后切换）。
- 场景按 `venue` 等级选择；设施按「已购买」状态显示，未购买不渲染、角色也不使用。
- 自主行为需按当前场地可用物件过滤（无冰箱就不去开冰箱）。

## 二、Bug
1. 读档跳过赛前确认：比赛日读档时，若当场首发未确认，应重新进入 18:30 赛前暂停弹窗。把"本场已确认"写进存档。
2. 一天时长统一：定义「09:00–22:00 可见白天 = 现实 10 分钟（正常档）」，22:00 后夜间快进约数秒；调整 clock 与文档表述一致。

## 三、体验
3. 饭点：去掉"外出吃饭"，M2 改为外卖（每饭点平均 2–3 人点，见外卖表草案）。M1 先让人留在座位吃/等待。
4. 事件看板默认展开日常条目（摸鱼、午睡、刷抖音、看直播等），让人一眼看到大家在干嘛。
5. 顶部 HUD 预留：现金、行动点、训练心得占位（M2 接真数据）。
6. 夜间快进时显示"大家都下班了"提示。
7. 性格新增「爱睡觉」字段，午睡概率由它驱动（不再只看摸鱼倾向）。

## 四、杂项
8. `scripts/screenshots.mjs` 去掉写死的 macOS Chrome 路径，README 注明 Windows/Linux 用 `CHROME` 环境变量。
