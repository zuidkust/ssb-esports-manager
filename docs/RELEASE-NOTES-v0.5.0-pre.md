# SSB电竞经理 v0.5.0-pre（M5 玩法补全）

网页试玩版。构建产物仍是单个 `index.html`，双击就能玩，不需要安装，也不是 Electron。

`game/package.json` 的版本号是 `0.5.0`；开始菜单和浏览器标签写 **v0.5.0-pre（M5 玩法补全）**。

## 怎么打开

```bash
cd game
npm install
npm test
npm run build
```

然后双击 `game/dist/index.html`。开发时用 `npm run dev`。

这一版构建出的 `game/dist/index.html` 是 **901,802 字节**（Vite 报 901.80 kB，gzip 264.35 kB）。脚本和样式都打进这一个文件，没有外链 JS。

## 这一版新增

**训练成长与路线特性**

- 六人新档自带默认路线：阿鸡/弟必 后期发育、当邓 游走节奏、狗粮 团战核心、吊隆 指挥大局、撇干 绝活专精。
- 每天 09:00 结算前一天的成长：路线主属性 ×2、副属性 ×1.3、其他 ×0.6；适配 S/A/B、专注手感、磨合期、摸鱼、体力/心情/疲劳都会影响。
- 主属性到 70 后成长开始放缓；之后每场比赛 30% 概率「开窍」，解锁路线特性（+4 属性 / 指挥官全队 +2 / 万金油适性 +0.05）。
- 换路线仍花 150 心得、磨合 3 天，并清掉当前已解锁特性。
- 人物卡新增「训练」：路线、适配、开窍线、昨日增长、特性状态。

**事件库 v1**

- 从 227 条旧素材里接入 **93 条**能映射到现行模型的日常事件：对局 30、摸鱼 25、生活 14、成长 14、甩锅与关系 10。
- 新增轻量排位结果：每 35 分钟给正在单排/双排/组排/训练的人一局胜负与连胜/连败，对局类事件用它做条件。
- 事件引擎支持条件、角色绑定、效果、分钟级冷却、flag、`chainNext` 权重。
- 看板平均约 134 行/天、最高 146；库事件约 8 条/天。

**平衡**

- 网吧/城市/国内的对手强度重新校准。自动排阵 + 默认战术 + 自动签赞助：网吧 11.60W（S1）/ 12.13W 总体、城市 9.20W（S2）/ 8.20W 总体、国内强制探针 6–7W（平均约 6.2）。
- 新增 `npm run balance`（20 种子 × 3 季 + 6 个国内探针），详见 `docs/数值-v0.5.md`。

**存档 v7**

新增 `routeTrait`、`routeTraitReady`、`abilityCarry`、`lastGain`、`slackMin`、`scrim`、`events`。旧 v6 存档自动迁移：补默认路线、成长字段和事件状态，不重算已经过去的天。

**调试**

只有地址带 `?debug=1` 时，左上角才会出现「调试」面板。只加 `?debug=1` 仍停在标题；再加 `&skip=1` 或 `&t=`、`&venue=` 才直接进入可玩的一局。常用跳转：`?day=2&t=18:20&skip=1`。

调试跳日不会补训练成长、心得和发薪；正常时间推进才会结算。

## 已知未做

- **美术/3D 挂起。** 人物仍是低多边形几何体（稿 B 剪影）；两条美术 draft 支线没有合并。上一轮摸底见 `docs/美术与3D-技术路线摸底-v1.md`。
- **事件库只接了日常 93 条。** 比赛日 27 条、监督 26 条、天意 25 条没有接入；18 条剧本连锁只保留了 `chainNext` 权重，剧本链没做。
- **事件文案的长尾。** 旧素材里被 `/` 切碎的 KDA 碎片已经过滤；仍有 10 条事件只有 1 个文案变体，没补到 4 条。
- **15 对默契连招的专名仍然【待定】**；比赛里只有狗粮×吊隆、弟必×当邓两对 +6%。
- **搬家费 30,000 与一季结余不匹配。** 自动经营三季约 14,300；不破产，但搬到城市要多攒几季或靠赞助。是否下调等真人试玩。
- **国内难度是强制探针。** 自动排阵 20 个种子里没有自然打进国内的球队（城市前 2 太少）；国内 6–7 胜的样本用“前两季成长后强制国内”跑出来，不是实际晋升路径。
- **不是 Electron。** 没有 Windows .exe；M6 再做打包。
- **DLC、BP/选人、重大事件自动暂停** 不在本版。
