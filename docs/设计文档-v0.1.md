# 英雄联盟办公室迷你世界 · 设计文档 v0.1

## 1. 核心概念
一个观察型养成"迷你世界"：一间办公室里的英雄联盟爱好者每天上班练级、摸鱼、组队参赛、慢慢进步。玩家像看《楚门的世界》一样旁观，通过画面和事件板了解发生了什么。世界时间与现实 1:1，玩家离线时世界照常运转。

## 2. 已定决策
| 项目 | 决定 |
|---|---|
| 玩家互动 | 纯旁观：看画面、点人物看状态、刷事件板 |
| 管理员干预 | 完全隐形，伪装成自然事件；后台保留仅管理员可见的干预日志 |
| 首发平台 | 独立网站，之后移植微信小程序（模拟逻辑放服务端，画面层单独适配） |
| 画面 | 3D 等距，尽量贴近参考图（Three.js，低多边形人物，柔和光照，光线随现实时间变化） |
| 成员 | 共 12 人，以用户真实朋友为原型；首批 6 人，其余后补 |
| 比赛 | 对手为虚拟队伍，系统模拟结果；每周一场周赛，每月一个杯赛 |
| 作息 | 9:00–17:00 上班，允许早到和加班；上班期间常摸鱼；有时五人组排，有时各自单排 |
| 管理角色 | 不设教练或老板，成员互相监督 |
| 比赛干预 | 管理员完全不碰比赛，只读查看 |
| 旁观访问 | 不用登录，直接公开，所有人看同一个实时世界 |

## 4. 世界运转
- 服务端常驻模拟，按分钟推进；所有人物状态、事件、比赛都在服务端生成。
- 白天：单排冲分、组排、复盘、摸鱼、午饭、互相"举报"摸鱼。
- 赛前 1–2 天进入备战氛围，组排比例提高；六人五位置，替补人选是每周话题。
- 17:00 后有人加班，有人溜号；夜间办公室变暗。

## 5. 摸鱼系统（种子）
看直播假装复盘、排队刷手机、拼单奶茶、带薪如厕、午睡"想战术"、开小号炸鱼、地鼠"如何评价"闲聊、施颠"版本研究"。被同事发现会触发举报、包庇、甩锅等连锁事件。

## 6. 比赛系统
虚拟对手队伍各有名字与风格；结果由双方实力、当日状态、心态、配合度和随机因素模拟；过程拆成对线、团战、转折点写入事件板，像文字直播。
