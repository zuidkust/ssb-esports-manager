# 峡谷打工人 · 迷你世界 —— HTML 交互样板

第一阶段视觉审核用样板。没有后端，世界由浏览器里的简易模拟器驱动，事件文案全部来自 `../data/events.json`。

## 怎么打开

**最简单**：双击上一级目录的 `样板-双击打开.html`（与 `dist/index.html` 相同，单文件、无需联网、无需服务器）。建议用 Chrome / Edge / Safari 最新版。

**开发模式**（改代码实时刷新）：

```bash
cd prototype
npm install
npm run dev          # 打开终端里显示的地址
npm run build        # 重新生成 dist/index.html（单文件）
npm run shots        # 用本机 Chrome 重新截图到 ../截图/
node scripts/engine-smoke.mjs      # 引擎冒烟测试：跑一天，打印事件分布和一场比赛
node scripts/interaction-test.mjs  # 交互自测：高速运行、点击人物、强制触发动作
```

改了事件库源文件后：`cd tools && python3 gen.py`，再 `npm run build`。

## 能看什么

| 功能 | 操作 |
|---|---|
| 实时世界 | 默认按真实北京时间运行；17:00 后大部分人下班，夜里只剩没关的显示器 |
| 旋转/缩放镜头 | 鼠标拖动、滚轮（手机：单指拖、双指缩放），角度有限制以保持等距感 |
| 人物卡片 | 点人物或头顶昵称；事件板里的人名也可点（镜头会移过去） |
| 事件板 | 日常灰字可折叠、有趣正常、剧情高亮带"后续可能"、重大置顶；点任意条目看参与者、前因、后果、画面定格 |
| 周赛文字直播 | 左下"样板审核工具"→「▶ 周赛文字直播（演示）」，节奏加速，约 1 分钟播完 |
| 时段审核 | 早晨/正午/傍晚/夜晚预设、时间滑杆、切换星期（周五为周赛日）、1×/60×/600× 加速、回到现在 |
| 手机竖屏 | 事件板变为底部抽屉（点把手或上下滑），审核工具收在 🛠 按钮里 |

### 审核链接参数

可以把某个状态直接发给别人看：

- `?t=14:50&wd=2` —— 周二 14:50
- `&speed=60` —— 60 倍速
- `&match=1` —— 打开就开始周赛直播
- `&card=shidian` —— 打开某人卡片（shidian 施颠 / dangdeng 当邓 / dishu 地鼠 / dibi 弟必 / diaolong 吊龙 / piju 批菊）
- `&q=low` —— 强制低画质；`&review=0` 收起审核工具；`&drawer=1` 展开手机抽屉

例：`样板-双击打开.html?t=13:15&wd=3`（午休：沙发上和趴桌睡觉的人）

## 代码结构

```
src/
  config.js            成员、对手、赛程等静态配置
  engine/              ← 服务端引擎的雏形（无渲染依赖）
    rules.js           条件 / 效果 DSL 解析与求值
    simulator.js       作息日程、行为、状态漂移、事件挑选、冷却、连锁、效果结算
    match.js           比赛模拟（开赛→对线→团战→转折点→结局）
    rng.js             种子随机数（同一天的日程可复现，拖动时间画面一致）
  world/clock.js       北京时间、审核模式、太阳高度角/方位角
  scene/               Three.js：办公室、人物、光照、导演层（行为→走位/姿态/气泡）
  ui/                  事件板、人物卡片、比赛直播面板
```

## 样板的简化（正式版会改）

- 事件密度约放大 5 倍（实时模式 4–8 秒一条），冷却按"演示分钟"计；因此重大事件约每天 1–2 条，远多于正式版的"每周 0–2 条"。
- 无法在前端判断的条件（如 `win`、`game_min`、部分统计型条件）按概率粗略放行。
- 不生成天意（管理员）事件；旁观人数是占位数字。
- 所有人物、家具都是代码拼出来的低多边形几何体，没有外部模型和贴图。
