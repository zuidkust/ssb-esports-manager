# 管理员后台 · 草案 v0.1

总原则：所有干预在前台都伪装成自然事件，旁观者无法分辨；后台保留完整的干预日志，仅管理员可见。

## 1. 入口与安全
- 独立地址（如 /admin），账号密码登录，可加二次验证。
- 仅管理员账号；后期可加"协管"角色（只能看不能改）。

## 2. 功能模块
### 2.1 世界总览（只读仪表盘）
- 实时 3D 画面（与前台一致）+ 上帝视角：显示每人头顶的状态条和"此刻想法"。
- 今日事件统计、各人状态、关系网热力图、近期胜率与段位曲线。
- 接下来 1 小时"可能发生"的事件预测（按当前概率排序）。

### 2.2 事件投放
- 从事件库选事件，指定参与者、发生时间（立即 / 定时 / 在某条件满足时）。
- 可直接启动一条连锁剧情，并选分支走向。
- 自定义事件：手写文案，系统检查文风后按普通事件发布。
- "合理性提示"：投放的事件与当前状态矛盾时提醒（例如让请假的人去组排）。

### 2.3 人物调整
- 改状态（体力、心情、专注、手感）：立即生效，前台由合理事件解释（如"喝了杯咖啡"）。
- 改能力与性格：设"目标值 + 过渡天数"，系统让它在几天里自然变化，避免突变穿帮。
- 改关系值、请假、迟到、加班。

### 2.4 比赛查看（只读）
- 管理员完全不干预比赛：不能指定结果、关键时刻或胜率，也不能编辑当场对手。
- 可查看下一场对手、双方实力和胜率预测，赛后查看完整模拟过程。
- 比赛进行期间（含赛前 1 小时）锁定对参赛成员的状态调整和事件投放，避免间接操控比赛。

### 2.5 世界环境
- 天气、停电、断网、空调坏了、外卖迟到、游戏版本更新等环境事件。
- 节假日与放假安排（是否上班）。

### 2.6 时间工具
- 暂停世界（前台显示"办公室今日休息"之类的自然理由）。
- 回放任意时间点的画面与事件。
- 不提供回滚和快进（保持 1:1 的真实感），如需可后期再加。

### 2.7 干预日志
- 记录每次操作：时间、操作者、内容、前台对应生成的伪装事件。
- 可撤销尚未发生的定时干预。

### 2.8 内容管理
- 事件库、文案模板、成员资料的增删改，改完热更新。
- 后续新增 6 名成员在这里录入。

## 3. 第一版范围建议
必做：世界总览、事件投放、人物状态调整、干预日志。
后做：自定义事件文风检查、事件预测、回放、协管角色、内容管理界面（初期直接改数据文件）。
