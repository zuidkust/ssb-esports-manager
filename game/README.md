# SSB电竞经理 · 网页版（M1）

设计依据：[`../docs/SSB电竞经理-设计文档-v0.3.md`](../docs/SSB电竞经理-设计文档-v0.3.md)。前期在 macOS 上用网页版开发和试玩，后期（M6）用 Electron 打包出 Windows .exe。

## 怎么玩

```bash
cd game
npm install
npm run dev      # 浏览器打开终端里显示的地址，改代码实时刷新
npm run build    # 生成 dist/index.html：单文件，双击就能玩，也可以发给朋友
```

操作：空格 暂停 / 继续 · `1` `2` `3` 正常 / ×3 / ×10 · `Esc` 存档菜单 · 拖动旋转、滚轮缩放 · 点人物看卡片。

存档保存在浏览器里（1 个自动存档 + 3 个手动槽位），每天开始、每 60 秒、关闭页面时自动存。换浏览器或清缓存会丢，重要进度用“导出存档”存成 JSON 文件，之后可以“从文件导入”。

## M1 做了什么

| 内容 | 说明 |
|---|---|
| 时间 | 09:00–22:00 可见白天 = 现实 10 分钟（正常档；×3、×10 按比例）；22:00 下班后约 6 秒快进夜间，屏幕提示“大家都下班了”；手动暂停 + 自动暂停 |
| 作息 | 6 段制：上班晨练 / 饭点 / 午休 / 下午组排 / 晚饭 / 自由时间；每人当日计划由存档种子决定，读档后一致。饭点都在工位等饭 / 吃饭（M2 换成外卖）。下午五黑每局 5 人，多出的 1 人轮流轮空（观战、吃东西、耍手机、看直播） |
| 自主行为 | 按性格和状态：单排、双排、刷手机（多数刷抖音，也有 B 站、小红书、短剧、手游等，或笼统的“耍手机”）、看直播、接水、闲聊、午睡、上厕所；有零食柜 / 冰箱 / 沙发时才会去拿零食、开冰箱、躺沙发。午睡概率由性格“爱睡觉”驱动 |
| 赛季 | 网吧联赛 8 队双循环 14 轮，每 2 天一轮；比赛日 18:30 自动暂停确认首发（已确认写进存档，暂停中关页 / 读档会重新弹），19:00 开赛（比赛引擎在 M3） |
| 存档 | `platform` 接口层（网页版 = localStorage，不可用时退回内存并提示导出）、版本号 + 迁移（当前 v2）、导出 / 导入 |
| 场地 | 开局是**网吧角落**：一排 6 台网吧机位（破皮椅子）、霓虹招牌「星空网吧」、价目表、路人网民、网管吧台、饮水机；没有沙发冰箱零食柜。打进城市联赛搬家后换成**小办公室**（M1 的等距办公室）。设施按“已购买”显示（`src/data/facilities.ts`），购买入口在 M4 |
| 画面 | 程序几何体 + Canvas 贴图：圆角家具、车削花盆 / 杯子 / 奖杯、电竞椅、机箱灯、褶皱窗帘；人物有眼白高光、眨眼、鞋子、耳机麦克风；环境反射光 |
| 界面 | 事件看板默认展开日常（摸鱼、午睡、刷抖音、看直播……）；顶部预留现金 / 行动点 / 训练心得（M2 接真数据） |

## 代码结构

```
src/
  core/      时钟、赛季日历、种子随机数（无渲染依赖，可单测）
  data/      角色数据（roster.ts，人设到了只改这里）、对手、刷手机 App 表、场地与设施（facilities.ts）
  sim/       作息与日常模拟（World）
  save/      存档结构、版本迁移、platform 接口层、槽位管理
  scene/     Three.js：场地（venue.ts 选场景；netcafe.ts 网吧角落、office.ts 小办公室）、人物、灯光、导演层（行为 → 走位 / 姿态）
  ui/        事件看板、人物卡片
tests/       vitest 单元测试
scripts/     screenshots.mjs（截图）、interaction-test.mjs（真机交互自测）
```

```bash
npm test                          # 单元测试
npm run typecheck
npm run shots                     # 构建后用本机 Chrome 截图到 shots/
node scripts/interaction-test.mjs # 构建后跑交互自测
```

截图和交互自测会自动找本机 Chrome（macOS / Windows / Linux 的常见安装位置）。找不到或想用别的浏览器时，用 `CHROME` 环境变量指定：

```bash
CHROME="/usr/bin/chromium" npm run shots                                         # Linux
$env:CHROME="C:\Program Files\Google\Chrome\Application\chrome.exe"; npm run shots  # Windows PowerShell
```

调试链接参数：`?day=2&t=18:20&speed=x10` 跳到某天某时刻（跳过标题，不写存档）；`&paused=1` 暂停；`&card=shidian` 打开人物卡；`&q=low` 低画质；`&venue=1` 换成小办公室（默认买齐该场地能买的设施），`&fac=snack,fridge` 指定已买设施，`&fac=none` 一件不买。

## 占位与待定

- 能力、性格、交情、次位都是占位数值（`src/data/roster.ts`），等详细人设。
- 首发目前按状态自动排；选首发、选战术、比赛直播在 M3。
- 事件引擎、老板动作、外卖小人在 M2；资源栏现在显示的是存档初始值。
- 设施购买、搬家在 M4；电竞基地、豪华基地的场景也在 M4，目前沿用小办公室。
- “爱睡觉”等性格值是占位。
