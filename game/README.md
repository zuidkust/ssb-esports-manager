# SSB电竞经理 · 网页版（M3）

设计依据：[`../docs/SSB电竞经理-设计文档-v0.3.md`](../docs/SSB电竞经理-设计文档-v0.3.md)。前期在 macOS 上用网页版开发和试玩，后期（M6）用 Electron 打包出 Windows .exe。

## 怎么玩

```bash
cd game
npm install
npm run dev      # 浏览器打开终端里显示的地址，改代码实时刷新
npm run build    # 生成 dist/index.html：单文件，双击就能玩，也可以发给朋友
```

操作：空格 暂停 / 继续 · `1` `2` `3` 正常 / ×3 / ×10 · `Esc` 存档菜单 · 顶部「经营」做老板动作、买设施、签赞助 · 拖动旋转、滚轮缩放 · 点人物看卡片。

## 打一场比赛

第 2 天是网吧联赛第 1 轮（之后每 2 天一轮，共 14 轮）。可以正常从第 1 天玩到晚上，也可以在地址后面加 `?day=2&t=18:20&skip=1` 直接跳到赛前。

1. **18:30** 自动暂停。弹出首发和战术：五个位置各选一人（6 人里必有 1 人在台下当第二解说），战术默认「强开团 / 运营发育」，另外三套用训练心得研究。选好后点「确认首发，开赛」。这一天的确认写进存档；暂停中关页面或读档，会重新弹出。
2. 时间走到 **19:00** 再自动暂停，打开直播。事件一条一条出来（节点、击杀、解说、弹幕），可以暂停或快进，但不会一键出结果。网吧联赛是 BO1；城市联赛起是 BO3，局间可以换人和换战术。
3. 看完点「记入积分榜，回到网吧」。胜负写入排名、赢场奖金和赞助进度（赢一场 +60 心得，输一场 +30）。赛季打完前 2 升级、后 2 降级；网吧联赛垫底不降级。国内前 2 只记下世界赛资格，这一阶段不开世界赛。

存档保存在浏览器里（1 个自动存档 + 3 个手动槽位），每天开始、每 60 秒、关闭页面时自动存。换浏览器或清缓存会丢，重要进度用“导出存档”存成 JSON 文件，之后可以“从文件导入”。

## M1 做了什么

| 内容 | 说明 |
|---|---|
| 时间 | 09:00–22:00 可见白天 = 现实 10 分钟（正常档；×3、×10 按比例）；22:00 下班后约 6 秒快进夜间，屏幕提示“大家都下班了”；手动暂停 + 自动暂停。低帧率和后台标签页按累计的真实时间走，一帧最多消化 15 秒 |
| 作息 | 6 段制：上班晨练 / 饭点 / 午休 / 下午组排 / 晚饭 / 自由时间；每人当日计划由存档种子决定，读档后一致。饭点有人点外卖，黄衣服外卖员送到工位；没点的人留在座位上。下午五黑每局 5 人，多出的 1 人轮流轮空（观战、吃东西、耍手机、看直播） |
| 自主行为 | 按性格和状态：单排、双排、刷手机（多数刷抖音，也有 B 站、小红书、短剧、手游等，或笼统的“耍手机”）、看直播、接水、闲聊、午睡、上厕所；有零食柜 / 冰箱 / 沙发时才会去拿零食、开冰箱、躺沙发。午睡概率由性格“爱睡觉”驱动 |
| 赛季 | 网吧 / 城市 / 国内联赛各 8 队双循环 14 轮，每 2 天一轮。比赛日 18:30 确认 5 人首发和战术（写进存档，暂停中关页 / 读档会重新弹），19:00 看直播。赛季末前 2 升级、后 2 降级，网吧联赛不降级。胜场和名次推进赞助 |
| 外卖 | 16 道菜（见 `docs/外卖表-草案v0.1.md`）。默认自己付钱；「今天我请」或公司餐补走公司账。大约 15% 的单触发连锁，同类冷却 3 天。本命外卖等人设，现在是通用文案 |
| 经营 | 每日行动点随场地 3→6，比赛日 +1。现金花费随联赛 ×1 / ×2 / ×4。对人冷却，滑动 7 天递减，第 4 次反噬。小办公室及以后的动作先锁住 |
| 经济 | 开局公司现金 5,000、私房钱 20,000。现金和训练心得两条线。每 28 天发工资和房租，连续 3 个月发不出才破产。赞助链 8 档，同时最多 2 个。顶部现金 / 行动点 / 心得是真数据 |
| 存档 | `platform` 接口层（网页版 = localStorage，不可用时退回内存并提示导出）、版本号 + 迁移（当前 v5）、导出 / 导入。存档列表和导出文件名用本地时间。不直接调用 Node 或 Electron，离线可玩 |
| 场地 | 开局是**网吧角落**：一排 6 台网吧机位（破皮椅子）、霓虹招牌「星空网吧」、价目表、路人网民、网管吧台、饮水机；没有沙发冰箱。零食柜要在经营里花 800 买了才出现。打进城市联赛搬家后换成**小办公室**（场景仍是 M1 的等距办公室）。设施按“已购买”显示（`src/data/facilities.ts`） |
| 画面 | 程序几何体 + Canvas 贴图：圆角家具、车削花盆 / 杯子 / 奖杯、电竞椅、机箱灯、褶皱窗帘；人物有眼白高光、眨眼、鞋子、耳机麦克风；环境反射光 |
| 界面 | 事件看板默认展开日常（摸鱼、午睡、刷抖音、看直播……）。「战队成立」固定在第 1 天 09:00。顶部显示现金、行动点、训练心得 |

## 代码结构

```
src/
  core/      时钟、赛季日历、种子随机数（无渲染依赖，可单测）
  engine/    比赛结算（纯函数，可单测）
  data/      角色数据（roster.ts，人设到了只改这里）、对手、战术、刷手机 App 表、场地与设施、外卖菜单、老板动作、赞助与经济常数
  sim/       作息与日常模拟（World）、联赛升降、首发、直播脚本、外卖、老板动作、经济、交情
  save/      存档结构、版本迁移、platform 接口层、槽位管理
  scene/     Three.js：场地（venue.ts 选场景；netcafe.ts 网吧角落、office.ts 小办公室）、人物、外卖员、灯光、导演层（行为 → 走位 / 姿态）
  ui/        事件看板、人物卡片、经营面板、赛前首发、直播
  debug/     测试用调试面板（仅地址带 ?debug=1 时出现）
tests/       vitest 单元测试
scripts/     screenshots.mjs（截图）、interaction-test.mjs（真机交互自测）
```

```bash
npm test                          # 单元测试
npm run typecheck
npm run shots                     # 构建后用本机 Chrome 截图到 shots/
node scripts/interaction-test.mjs # 构建后跑交互自测
```

截图和交互自测会自动找本机 Chrome（macOS / Windows / Linux 的常见安装位置）。找不到或想用别的浏览器时，用 `CHROME` 环境变量指定：

```bash
CHROME="/usr/bin/chromium" npm run shots                                         # Linux
$env:CHROME="C:\Program Files\Google\Chrome\Application\chrome.exe"; npm run shots  # Windows PowerShell
```

调试链接参数：`?day=2&t=18:20&speed=x10` 跳到某天某时刻（跳过标题，不写存档）；`&paused=1` 暂停；`&card=aji` 打开人物卡；`&q=low` 低画质；`&venue=1` 换成小办公室（默认买齐该场地能买的设施），`&fac=snack,fridge` 指定已买设施，`&fac=none` 一件不买。测试面板见下方「调试模式」，只有 `?debug=1` 才会出现。

## 调试模式（仅测试）

地址加上 `?debug=1` 才会在左上角出现「调试」面板，默认收起。不加这个参数时，页面上没有调试入口，也不会多出任何按钮。

面板里的改动不写进存档格式。自定义倍速（×1 到 ×60）只在当次打开的页面里生效；22:00 之后那段大约 6 秒的夜间快进不看这个倍率。玩家原来的 `1` / `2` / `3` 和底部「正常 / ×3 / ×10」不变，点它们会清掉自定义倍速。

只加 `?debug=1` 仍会停在标题。要直接进入可玩的一局，再加上 `&skip=1`，或沿用原来的 `&t=`、`&venue=`。在标题画面上使用面板里的跳转或改数，会把背后这一局当成正式开局。

面板可以：

- 跳到指定的一天和时刻，例如第 29 天 12:00。作息、活动和站位按读档的方式重算：不重放中间那些天，也不补发已经过去的工资。
- 下一顿外卖（落到外卖员进门的时刻）、下一场比赛（停在 19:00，先确认首发再进直播）、下一次发薪、下一事件。发薪按钮只结算接下来的那一次，停在当天 09:00 并暂停；人还停在这一刻时再按一次，不会跳到再下一个月。下一顿外卖如果会越过比赛夜 18:30，就停在赛前暂停。天数、时刻、现金、行动点、倍速、场地、队员、外卖和连锁都有文字标签。上面的指定跳转不会发薪。下一事件是下一个作息节点（上班、午饭、午休、组排、晚饭、赛前、开赛、赛后、自由时间、下班；跨天时如果第二天是发薪日就标成发薪）。
- 暂停，以及 ×1 到 ×60 的自由倍速。
- 改现金、行动点和场地等级。已经买下的设施还在；当前场地用不上的会先藏起来。跳转会像读档那样把当天行动点补回上限，所以改行动点要放在跳完之后。
- 给指定队员点一单外卖，或强制触发一种外卖连锁（螺蛳粉抗议、麻辣烫超预算会换成对应的菜）。
- 清空全部冷却，包括老板动作和外卖连锁。

## 占位与待定

- 默契连招的名字仍是【待定】。铁哥们（交情 ≥ 85）且同时首发时，狗粮×吊隆、弟必×当邓的相关节点 +6%。
- 撇干选人永远是剑魔，战力 +30%，英雄池跳过石头人。狗粮「只玩一把」：系列赛第 1 局属性 +6，第 2 局归零，第 3 局 −6。
- 搬家、电竞基地和豪华基地的场景在 M4，目前升级只改联赛级别，场地先不搬。世界赛只记资格，不开淘汰赛。网吧能买的零食柜、耳机已经可以买。
- “爱睡觉”等性格值是占位。
- 标了【待定】的默认（发薪 28 天、今天我请按实价、摸鱼 90 分钟不产出心得等）写在设计文档第 15 章。
