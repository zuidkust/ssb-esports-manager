# SSB电竞经理 · 网页版（M1）

设计依据：[`../docs/SSB电竞经理-设计文档-v0.3.md`](../docs/SSB电竞经理-设计文档-v0.3.md)。前期在 macOS 上用网页版开发和试玩，后期（M6）用 Electron 打包出 Windows .exe。

## 怎么玩

```bash
cd game
npm install
npm run dev      # 浏览器打开终端里显示的地址，改代码实时刷新
npm run build    # 生成 dist/index.html：单文件，双击就能玩，也可以发给朋友
```

操作：空格 暂停 / 继续 · `1` `2` `3` 正常 / ×3 / ×10 · `Esc` 存档菜单 · 拖动旋转、滚轮缩放 · 点人物看卡片。

存档保存在浏览器里（1 个自动存档 + 3 个手动槽位），每天开始、每 60 秒、关闭页面时自动存。换浏览器或清缓存会丢，重要进度用“导出存档”存成 JSON 文件，之后可以“从文件导入”。

## M1 做了什么

| 内容 | 说明 |
|---|---|
| 时间 | 白天 08:30–22:30 = 现实 10 分钟（×3、×10 按比例）；22:30 后约 6 秒快进夜间；手动暂停 + 自动暂停 |
| 作息 | 6 段制：上班晨练 / 饭点 / 午休 / 下午组排 / 晚饭 / 自由时间；每人当日计划由存档种子决定，读档后一致 |
| 自主行为 | 按性格和状态：单排、双排、刷手机（多数刷抖音，也有 B 站、小红书、短剧、手游等，或笼统的“耍手机”）、看直播、去零食柜、开冰箱、接水、闲聊、午睡（趴桌 / 沙发）、上厕所、出去吃饭 |
| 赛季 | 网吧联赛 8 队双循环 14 轮，每 2 天一轮；比赛日 18:30 自动暂停确认首发，19:00 开赛（比赛引擎在 M3） |
| 存档 | `platform` 接口层（网页版 = localStorage，不可用时退回内存并提示导出）、版本号 + 迁移、导出 / 导入 |
| 画面 | 沿用样板的等距办公室，模型稍作精细：圆角家具、车削出的花盆 / 杯子 / 奖杯、电竞椅侧翼与轮子、机箱灯、褶皱窗帘、书架；人物有眼白高光、眨眼、鞋子、短袖、耳机麦克风；环境反射光 |

## 代码结构

```
src/
  core/      时钟、赛季日历、种子随机数（无渲染依赖，可单测）
  data/      角色数据（roster.ts，人设到了只改这里）、对手、刷手机 App 表
  sim/       作息与日常模拟（World）
  save/      存档结构、版本迁移、platform 接口层、槽位管理
  scene/     Three.js：办公室、人物、灯光、导演层（行为 → 走位 / 姿态）
  ui/        事件看板、人物卡片
tests/       vitest 单元测试
scripts/     screenshots.mjs（截图）、interaction-test.mjs（真机交互自测）
```

```bash
npm test                          # 单元测试
npm run typecheck
npm run shots                     # 构建后用本机 Chrome 截图到 shots/
node scripts/interaction-test.mjs # 构建后跑交互自测
```

调试链接参数：`?day=2&t=18:20&speed=x10` 跳到某天某时刻（跳过标题，不写存档）；`&paused=1` 暂停；`&card=shidian` 打开人物卡；`&q=low` 低画质。
